# Комод

Демонстрационный сайт кофейни в Самаре. Меню завтраков, фотографии, атмосфера заведения и контакты с локальной подготовкой заявки.

![Первый экран сайта «Комод»](docs/screenshots/portfolio-preview.png)

[Открыть демо](https://kaigo.space/site/comod/)

## Реализация

React, TypeScript и Vite. Адаптивные секции, карусели, навигация, локальные медиа и контроль их происхождения. Форма не отправляет заявку автоматически: это демонстрационный интерфейс.

## Локальный запуск

```bash
npm ci
npm run dev
```

Адрес: [127.0.0.1:4173](http://127.0.0.1:4173/).

```bash
npm run verify
```

Команда объединяет проверки типов, линтер, unit-тесты, проверку media manifest и сборку. Браузерные сценарии требуют установленного Chromium для Playwright.

Подробные инструкции, источники и ограничения сохранены в [IMPLEMENTATION.md](IMPLEMENTATION.md). Скриншот снят с публичного демо 9 сентября 2026 года; весь набор тестов при обновлении документации не перезапускался.

Портфолио-демо, не заявление об официальном сотрудничестве. Фотографии и бренд не лицензируются от имени автора кода; перед повторным использованием материалов нужно проверить права.
